# PDF Desk

DocuWorks 스타일의 문서 관리/편집 프로그램입니다. Flutter로 만든 **Windows 64비트(x64, ARM64)** 데스크톱 앱이며, 문서 형식으로 표준 PDF를 사용합니다.

## 주요 기능

### 데스크 (DocuWorks Desk 대응)
| 기능 | 조작 |
|---|---|
| 문서를 종이처럼 자유 배치 | 끌어서 이동. 문서끼리 겹쳐 놓을 수 있고, 클릭한 문서가 맨 위로 올라옴. 위치와 겹침 순서는 폴더별로 저장됨 |
| 쌓인 모양 | 여러 장짜리 문서는 아래 종이의 가장자리가 보이도록 겹친 모양으로 표시 |
| 겹치기 | 문서를 다른 문서 위에 끌어다 놓으면 메뉴 없이 바로 그 문서 뒤에 페이지가 붙음. 합친 문서를 또 다른 문서에 계속 겹칠 수 있음. 아래에 뜨는 `실행 취소`로 직전 겹치기를 되돌림. `Shift`를 누른 채 놓으면 합치지 않고 위에 올려놓기만 함. 여러 개를 선택하고 `겹치기` 버튼을 눌러도 됨 |
| 미리보기 | 툴바의 `미리보기`(또는 `표시` 메뉴)로 오른쪽 미리보기 창을 켜고 끔. 클릭한 문서가 표시되고, 여러 장이면 ◀ ▶ 버튼, `←`/`→`, `PageUp`/`PageDown`, 마우스 휠로 페이지를 넘김. 창 너비는 경계선을 끌어 조절 |
| 펼치기 | 여러 개를 한꺼번에 펼치면 문서마다 한 줄씩 놓임. 여러 장짜리 문서를 한 장씩 낱장 문서로 나눠 그 자리에 나란히 펼침. 바인더는 풀어서 펼침. 겹치기로 다시 합칠 수 있음 |
| 데스크 이동 | 가운데 버튼으로 끌어서 데스크를 이동 |
| 확대·축소 | `Ctrl`+마우스 휠로 데스크의 문서 크기를 키우고 줄임(마우스 위치 기준). 상태 막대 슬라이더나 `표시` 메뉴로도 가능 |
| 클릭 범위 | 문서는 그려진 종이 크기만큼만 클릭·선택됨. 가로 문서나 작은 문서 주변의 빈 곳은 데스크로 취급 |
| 복사 | 문서를 선택하고 `Ctrl`을 누른 채 끌어 놓으면 그 자리에 복사본이 생김(주석 포함). 끄는 동안 초록색 `+` 표시 |
| 새 문서 작성 | 데스크 빈 곳 우클릭 → `새 문서 작성…`(또는 `Ctrl+N`). 용지(A3·A4·A5·B4·B5·Letter·Legal), 방향, 쪽 수를 골라 빈 문서를 그 자리에 놓음 |
| 가져오기 | 탐색기에서 PDF·이미지(jpg/png/bmp/gif/webp/tif)를 끌어다 놓기, 또는 `Ctrl+O`. 이미지는 PDF로 변환됨 |
| 다중 선택 | `Ctrl`/`Shift`+클릭, 빈 곳을 드래그해 범위 선택, `Ctrl+A`. 드래그로 고르면 화면 순서(위→아래, 왼쪽→오른쪽)대로 선택됨 |
| 선택 바 | 2개 이상 선택하면 바로 위에 `겹치기 · 펼치기 · 바인더` 버튼이 뜸 |
| 새로 묶기 | 여러 문서로 이름을 붙인 새 문서 만들기 (원본 유지 가능) |
| 분할 | 원본을 남겨 두고 페이지마다 별도 문서로 나누기 (메뉴의 `문서`나 우클릭) |
| 메뉴 막대 | 파일 · 편집 · 문서 · 표시 메뉴에서 모든 명령 사용 가능 |
| 바인더 | 여러 문서를 바인더로 묶고(뷰어에서 탭으로 표시), 해제. 바인더 위에 문서를 놓으면 추가됨 |
| 폴더 | 왼쪽 위 트리에서 폴더 만들기/이름 변경/삭제. 문서를 폴더로 끌어다 놓으면 이동 |
| 내 PC | 왼쪽 아래에 바탕 화면·문서·다운로드와 모든 드라이브(C:, D: …)가 탐색기처럼 표시됨. PDF·이미지를 데스크로 끌면 **옮겨지고**(`Ctrl`: 복사), 데스크 문서를 디스크 폴더로 끌면 **복사됨**(주석은 PDF에 새겨지고 바인더는 한 PDF로). 디스크 폴더 우클릭 → `데스크로 열기`로 그 폴더를 바로 데스크로 사용 |
| 바탕 화면·탐색기로 끌기 | 데스크 문서를 창 밖으로 끌어 바탕 화면이나 탐색기 폴더에 놓으면 같은 이름으로 복사됨(데스크에는 그대로 남음). 주석이 있으면 주석을 새긴 PDF로, 바인더는 한 PDF로. 반대 방향(탐색기 → 데스크)도 끌어 놓기로 가능 |
| 휴지통 | 삭제한 문서는 휴지통으로 가고(30일 보관), 삭제 직후 `실행 취소` 또는 `파일` → `휴지통…`에서 복원 |
| 기타 | 회전, 이름 바꾸기(`F2`), 복제(`Ctrl+D`), 삭제(`Del`), 정렬(이름순/수정일순), 이름 검색 |
| 언어 | 오른쪽 위 🌐 메뉴에서 한국어 · 日本語 · 中文 · English · Español · Français 선택(설정에 저장됨) |
| 테마 | 오른쪽 위 🎨에서 iOS 라이트 · iOS 다크 · 클래식(DocuWorks) · 종이(세피아) · 포레스트 · 미드나이트 |
| 출력 | PDF 내보내기(주석 포함), 인쇄(`Ctrl+P`) |

### PDF Desk 프린터 (DocuWorks Printer 대응)
다른 프로그램(Word, 브라우저 등)에서 **PDF Desk** 프린터로 인쇄하면, 저장 창 없이 문서가 지금 열린 데스크에 바로 놓입니다.

- 설치: 처음 실행할 때 아래에 뜨는 안내의 `설치`, 또는 `파일` → `'PDF Desk' 프린터 설치/설정…`(환경 설정) → `설치`. 한 번 관리자 권한(UAC) 확인이 뜹니다.
- 설치하면 **기본 프린터로 지정**되므로 어떤 프로그램에서든 `Ctrl+P`로 인쇄하면 데스크에 놓입니다. (Windows가 마지막에 쓴 프린터로 기본값을 바꾸는 기능도 꺼 둡니다.) 환경 설정에서 언제든 `기본 프린터로`를 다시 누를 수 있습니다.
- 일반 "Microsoft Print to PDF"를 고르면 저장 위치를 묻는 창이 뜨고 데스크로 오지 않습니다. 데스크로 보내려면 **PDF Desk** 프린터를 고르세요.
- Windows에 들어 있는 "Microsoft Print to PDF" 드라이버를 쓰므로 별도 드라이버가 없고, x64와 ARM64에서 똑같이 동작합니다. 그 기능이 꺼져 있다면 "Windows 기능 켜기/끄기"에서 켜세요.
- 인쇄물은 `인쇄_날짜_시간.pdf`라는 이름으로 놓입니다. 환경 설정에서 "한 문서로 놓기"와 "낱장으로 펼쳐 놓기" 중 하나를 고를 수 있습니다.
- 프린터는 항상 같은 파일(`%APPDATA%\…\inbox\print.pdf`)에 씁니다. PDF Desk가 꺼져 있을 때 두 번 인쇄하면 앞의 인쇄물이 덮어써지므로, 인쇄할 때는 앱을 켜 두세요.

### 뷰어 (DocuWorks Viewer 대응)
- **주석**: 펜, 형광펜, 직선, 화살표, 사각형, 타원, 텍스트, 부전(스티커 메모), 날짜 도장, 지우개
  - 선택 도구로 이동, 모서리 핸들로 크기 조절, 더블클릭으로 텍스트 편집
  - `Shift`+드래그: 45° 단위 직선, 정사각형, 정원
  - 주석을 선택하고 **우클릭 → `속성…`**(또는 도구 막대의 `속성…`): 선 색, 굵기(사각형·타원은 `없음` 가능), 선 종류(실선·파선·점선·일점쇄선), 화살표(시작점/끝점), 배경색과 불투명도, 글꼴·크기·굵게·기울임·글자색. 바뀌는 모습이 바로 보이고, 한 번의 `실행 취소`로 되돌아감
  - 도구 막대에서 새로 그릴 도형의 색·굵기·선 종류·배경, 텍스트의 글꼴(맑은 고딕, 굴림, 돋움, 바탕, 궁서, 나눔고딕, 나눔명조, Arial, Times New Roman 등)을 미리 고를 수 있음
  - 색상은 빠른 색 외에 🎨 버튼으로 126색 팔레트, 최근 사용한 색, `#RRGGBB` 직접 입력
  - 복사/붙여넣기, 맨 앞/뒤로, 주석 표시/숨기기
  - 실행 취소/다시 실행 (`Ctrl+Z`, `Ctrl+Y`), 자동 저장
- **영역 복사**: 도구 막대의 `영역 복사`(가위)로 페이지의 일부를 끌어서 고르면 그림으로 복사됨(그 안의 주석 포함, 글자는 Windows 클립보드에도 복사). 다른 문서에서 `Ctrl+V`로 붙여 넣고 옮기거나 크기 조절. PDF 내보내기·인쇄에도 들어감
- **페이지 편집**(왼쪽 페이지 목록): 드래그로 순서 변경, 회전, 삭제, 추출(새 문서로), 앞/뒤에 파일 삽입
- 문서 안 텍스트 검색(`Ctrl+F`, `F3`), 확대/축소(`Ctrl+휠`, `Ctrl +/-`), 폭 맞춤(`Ctrl+0`), 전체 페이지 보기
- 바인더를 열면 문서마다 탭이 생김. 탭을 우클릭해 순서 변경, 이름 변경, 바인더에서 꺼내기

### 도움말
`도움말` 메뉴에 사용 설명서(`F1`, 11개 장), 단축키, 프로그램 정보(버전, 오픈 소스 라이선스)가 있습니다. 설명서는 6개 언어(한국어·日本語·中文·English·Español·Français)로 되어 있어, 고른 언어로 보입니다.

### 주석 저장 방식
DocuWorks처럼 **주석은 원본과 분리된 레이어**로 보관되므로 원본 PDF가 바뀌지 않습니다. 언제든 수정하거나 지울 수 있습니다.
내보낸 PDF(내보내기, 폴더로 복사, 창 밖으로 끌기)에는 주석이 편집 정보로도 함께 들어 있어서, 다시 데스크로 가져오면 새겨진 그림을 걷어 내고 **고칠 수 있는 주석으로 복원**합니다. "PDF 내보내기"나 "인쇄"를 하면 주석이 PDF 안에 실제 벡터/텍스트로 새겨지며(선 종류·배경·글꼴 포함, 고른 글꼴을 PDF에 넣음), 어떤 PDF 뷰어에서도 똑같이 보입니다. 굵게/기울임 글꼴 파일이 없는 글꼴은 획을 두껍게/기울여서 표현합니다.

```text
데스크폴더/
  견적서.pdf
  2026 보고서.pdbinder/         ← 바인더 (폴더)
    1월.pdf
    binder.json                ← 문서 순서
  .pdfdesk/
    layout.json                ← 데스크 위 문서 위치
    annotations/견적서.pdf.json ← 주석
```

기본 데스크 폴더는 `C:\Users\<이름>\PdfDesk`입니다. OneDrive가 동기화하는 `문서` 폴더에 두면 파일을 잡고 있어 "사용 중" 오류가 나므로 피했고, 예전 버전처럼 OneDrive 안에 있으면 시작할 때 옮길지 묻습니다. 환경 설정(톱니바퀴)에서 바꿀 수 있습니다. 도장의 문구와 이름도 환경 설정에서 정합니다.

## Windows에서 빌드하기

준비물:
1. [Flutter SDK](https://docs.flutter.dev/get-started/install/windows) 3.44 이상
2. Visual Studio 2022의 **"C++를 사용한 데스크톱 개발"** 워크로드

```powershell
flutter pub get
flutter run -d windows             # 개발 실행
flutter build windows --release    # 배포용 빌드
```

결과물은 `build\windows\x64\runner\Release\`에 생깁니다. 이 폴더 전체(`pdf_desk.exe`, `pdfium.dll`, `msvcp140.dll`, `vcruntime140*.dll`, `data\` 등)를 복사하면 다른 PC에서도 실행됩니다. Visual C++ 런타임 DLL이 함께 들어가므로 대상 PC에 재배포 패키지를 설치할 필요가 없습니다.
ARM64 PC에서 빌드하면 ARM64용이 만들어집니다.

GitHub에 올리면 `.github/workflows/build-windows.yml`이 자동으로 x64 빌드를 만듭니다.

## 테스트

```powershell
flutter test
```

- `test/pdf_ops_test.dart`: 묶기, 분할, 회전, 순서 변경, 삭제 시 주석 위치 유지, 주석 새기기(회전된 페이지 포함), 이미지 가져오기, 바인더
- `test/ui_smoke_test.dart`: 데스크 표시, 선택, 뷰어 열기, 펜으로 그리기, 자동 저장
- 한글 새기기 테스트는 Windows에서 맑은 고딕을 자동으로 사용합니다. 다른 OS에서는 `PDFDESK_FONT=한글.ttf`를 지정하세요.

## 구조

```text
lib/
  models/annotation.dart          주석 모델 (JSON, 충돌 판정, 회전)
  services/
    pdf_ops.dart                  묶기/분할/페이지 편집/가져오기/바인더 (pdfrx = PDFium)
    flatten.dart                  주석을 PDF에 새기기 (PDFium FFI)
    storage.dart                  주석/배치/바인더 파일 저장
    thumbnails.dart               썸네일 캐시 (동시 렌더링 제한)
    desk_controller.dart          데스크 상태, 폴더 감시
    print_inbox.dart              PDF Desk 프린터 인쇄물 받기
    virtual_printer.dart          PDF Desk 프린터 설치/제거 (PowerShell)
  ui/desk/                        데스크 화면, 폴더 트리, 캔버스
  ui/viewer/                      뷰어, 페이지 목록, 주석 입력 레이어
```

## 아직 없는 기능
- DocuWorks 고유 형식(.xdw/.xbd) 읽기·쓰기 (형식이 공개되어 있지 않음)
- OCR, 스캐너 연동
- 전자 서명, 문서 암호 설정
- 여러 뷰어 창 동시 열기 (현재는 데스크 → 뷰어 화면 전환)
